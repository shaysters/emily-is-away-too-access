A small update for copies of the game from outside Steam.

- If some part of the mod can't hook into a copy of the game, only that part is skipped; the rest still works. This is for the DRM-free itch.io download of Emily is Away Too, which hasn't been tested yet: in the installer, use the Browse button and choose the folder that contains `EmilyIsAwayToo.exe`. Emily Online is a Steam messenger, so it needs the Steam copy.

To update, run **EmilyIsAwayTooAccessInstaller.exe** again (or download it below), or extract **EmilyIsAwayTooAccess.zip** into the game folder.
