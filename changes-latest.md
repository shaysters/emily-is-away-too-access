The first release of Emily is Away Too Access, for Emily is Away Too and Emily Online.

Download **EmilyIsAwayTooAccessInstaller.exe** below and run it: it finds the game, installs BepInEx and both mods. Or install by hand with **EmilyIsAwayTooAccess.zip** (see the README).

- Emily is Away Too, all five chapters with both story paths and the ending: both chat windows read aloud, reply choices, your reply word by word with erased text, reply timers (twice as long by default, adjustable or off), links, files, typed answers, profiles, buddy list and statuses.
- The fake installer, menus, sign-in, icon picker, profile questions, colour pickers, icon gallery with secret codes, and pop-ups (which start on Cancel) all work from the keyboard.
- Descriptions of every buddy icon, the desktop backgrounds, chapter pictures, banner ads and Emily's art project.
- Emily Online: your Steam friends' buddy list with statuses, chats read aloud, the message box with each letter read, the eight emotes by name, warnings, profiles and profile editing.
- Speech and braille through Prism: NVDA, JAWS and other screen readers, or Windows' own voices.
