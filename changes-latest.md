A new setting for typing.

- You can now turn off the mod reading each letter you type: in Emily Online's message box, and in Emily is Away Too's sign-in boxes, code box and your own typed answers. Turn it off if your screen reader already says the keys you type, so you don't hear each letter twice. It's the first item in Emily Online's settings (Ctrl+M), and the last in Emily is Away Too's (m). It stays on unless you turn it off.

To update, run **EmilyIsAwayTooAccessInstaller.exe** again (or download it below), or extract **EmilyIsAwayTooAccess.zip** into the game folder.
