A clearer start to each chapter, and a typing change in Emily Online.

- The profile at the start of each chapter now goes one step at a time. After you pick your buddy icon, each question (music, a movie, a saying) is read on its own when it's your turn, with what you picked, and the arrow keys start on its answers. Each answer says which question it's for ("Movie: 2. the departed").
- The chats wait until your profile is finished (or until you leave the profile window), so messages don't talk over the questions.
- Emily Online: "is typing" is read for any buddy, open chat or not, whenever Steam sends it. Note that in testing, Steam didn't pass typing notices on to Emily Online, so the game can't show them either.

To update, run **EmilyIsAwayTooAccessInstaller.exe** again (or download it below), or extract **EmilyIsAwayTooAccess.zip** into the game folder.
