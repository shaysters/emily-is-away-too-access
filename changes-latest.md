Clearer start to each chapter, and a typing change in Emily Online.

- After you pick your buddy icon, the mod now explains the profile screen: pick some music, a movie and a saying with 1, 2 or 3, and your buddies start messaging after your first pick (Tab opens their chat). Each question says what it's for. Before, "Icon set to" cut this explanation off.
- Emily Online: "is typing" is read for any buddy, open chat or not, whenever Steam sends it. Note that in testing, Steam didn't pass typing notices on to Emily Online, so the game can't show them either.

To update, run **EmilyIsAwayTooAccessInstaller.exe** again (or download it below), or extract **EmilyIsAwayTooAccess.zip** into the game folder.
